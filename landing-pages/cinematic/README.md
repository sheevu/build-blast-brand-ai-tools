# Cinematic landing page

Isolated new page: `/cinematic/index.html`. Existing application files, navigation and styles remain unchanged.

## Rebuild
Run `npm ci` in this directory, then `node node_modules/esbuild/bin/esbuild main.js --bundle --minify --outfile=../../public/cinematic/app.js --legal-comments=eof`.
Edit HTML and CSS directly in `public/cinematic/`. Serve the public directory to preview.

## Motion and assets
Three.js renders the interactive growth sculpture; Motion provides scroll reveals; Lottie renders an original animated signal. All runtimes are bundled locally. System reduced-motion preferences and the pause button stop decorative animations. YouTube is loaded when the visitor clicks play; a direct watch link is also provided.

The user supplied the motion-study MP4, gaming video and route-map JPEG. The two motion-study inputs are byte-identical, so one is retained. The gaming backdrop is a muted 12-second compressed excerpt. The study is explicitly labelled as a supplied visual reference, not an agency client project. No paid marketplace assets, Spline project, Webflow project or Jitter exports were supplied or purchased; those services are not claimed as integrations.

Google Fonts are externally hosted. Service and enquiry links use the existing Vyapai destination pages and WhatsApp number. No message is sent automatically.
